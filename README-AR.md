# DOCAI-GEMINI ERP — نسخة الإصلاح الأولية

هذه نسخة منفصلة مبنية على النسخة الاحتياطية المرفقة. لم يتم تعديل مخطط تخزين المرضى أو السندات أو المخزون أو المصروفات.

## التغييرات المنفذة

1. **الذكاء الاصطناعي**
   - استبدال قائمة النماذج الثابتة باكتشاف مباشر من Google Gemini وGroq وOpenRouter.
   - اختبار كل نموذج مرشح منفردًا بطلب صغير قبل عرضه باعتباره عاملًا.
   - تضمين دعم OpenRouter في التوجيه الفعلي، بدل عرض إعداد المفتاح دون استعماله.
   - التوجيه التلقائي يجرب النماذج التي اجتازت الاختبار فقط، وينتقل إلى نموذج آخر عند فشل أحدها.
   - لا توجد نماذج وهمية عند غياب المفاتيح؛ العدد النهائي يتوقف على النماذج المتاحة وصلاحية المفاتيح والحصص.
   - عند وجود مفتاح محفوظ، يحاول النظام تحديث قائمة النماذج عند بدء التشغيل.

2. **السند والصيغة**
   - حفظ اختيار A5 أو 80mm مع بيانات السند واستعادته عند فتح السند للتعديل.
   - إصلاح خطأ كان يجعل تصدير PDF يستخدم A5 دائمًا حتى عند اختيار 80mm.

3. **QR**
   - إبقاء توليد QR محليًا بمكتبة QRCode.js، مع رابط CDN بديل عند فشل المصدر الأول.
   - إلغاء الاعتماد على صورة QR خارجية كحل احتياطي لأنها قد تفشل دون إنترنت أو تمنع تصدير PDF عبر html2canvas.
   - إذا فشل تحميل المكتبتين، سيظهر تنبيه واضح بدل صورة بعيدة قد لا تعمل.

4. **التنقل والتصميم**
   - إزالة شريط التبويبات الأفقي المكرر من أعلى الصفحة، لتصبح القائمة الجانبية هي طريق التنقل الوحيد.
   - إضافة قواعد responsive للهاتف، مع الحفاظ على الأقسام الستة ووظائفها.
   - عدم تغيير مخطط البيانات أو حذف الوظائف الأساسية عمدًا.

## الاختبارات المنفذة

- اجتازت ملفات JavaScript الخمسة فحص `node --check`.
- فحص HTML: 128 معرّفًا فريدًا، دون معرّفات مكررة.
- تأكيد وجود الأقسام الستة، وحاوية QR، واختيار صيغة الورق، وملفات JavaScript المطلوبة.
- لم يمكن التحقق من اتصال المزودين أو توفر 25 نموذجًا أو اختبار الطباعة الفعلية دون مفاتيح API واتصال المتصفح بخدمات المزودين.
- يجب تجربة QR وتصدير PDF على الهاتف بعد فتح النسخة عبر HTTP/HTTPS، لأن تشغيل الملفات مباشرة قد يختلف عن بيئة النشر.

## طريقة التشغيل

افتح `index.html` عبر الاستضافة الحالية أو خادم HTTP. من الإعدادات، أدخل مفاتيح المزودين التي تملكها، احفظ الإعدادات، ثم اضغط **فحص النماذج المتاحة**. لا تضع المفاتيح في ملفات عامة أو تشاركها مع أي شخص.

> ملاحظة أمان: هذه نسخة واجهة أمامية وتحتفظ بمفاتيح المزودين في تخزين المتصفح كما كان في التصميم الأصلي. للنشر العام متعدد المستخدمين، ينبغي نقل استدعاءات المزودين إلى خادم وسيط مع Secrets بدل كشف المفاتيح للمتصفح. لم أغيّر المعمارية الأساسية ضمن هذه الجولة لتجنب تعطيل الوظائف الحالية.
